# VISUAL MORPHOLOGY LEDGER

**Status:** Working control ledger  
**Office:** Masterwork Formation / Visual Art  
**Purpose:** Track used visual surface grammar so successful graphics do not harden into a house style.

---

# GOVERNING LAW

> **INHERIT OPERATIONS, NOT SURFACES.**

> **SUCCESS DOES NOT CREATE A HOUSE STYLE.**

A new Collision Field must earn its own visual grammar from its own gravity.

This ledger records visual morphology, not artistic value.

---

# TRACK FOR EVERY KEPT GRAPHIC

- Collision Field / title
- body fragment(s)
- body placement
- giving / receiving motion
- field topology
- dominant material
- spatial grammar
- horizon / depth structure
- palette / illumination
- hand / gesture use
- recurring motifs
- near / middle / far behavior
- discovered gestalt or second read
- genuinely new visual operation
- spent / high-recurrence features created by this deposit

---

# CURRENT HIGH-RECURRENCE / SPENT WARNING

The recent graphic sequence has overused the following family:

- large flesh fragment along one edge;
- isolated hand or fingertips from another edge;
- luminous webbing / filament / membrane networks;
- giant open fantasy-like landscape;
- arches / bridges / towers / portal-like forms;
- warm gold + cyan / blue illumination;
- radiant horizon;
- hand appearing to pull, pluck, thread, or manipulate filament.

These features are **not banned forever**.

They are now **SPENT BY DEFAULT**.

They may return only if the current Collision Field independently earns them and the prompt explicitly states why the recurrence is necessary.

A new concept placed inside this same morphology does **not** count as a new graphic.

---

# DISCOVERED OPERATION TO PRESERVE WITHOUT COPYING SURFACE

A strong prior image produced an unintended anatomical gestalt in which one flesh contour could be read in more than one way while field motion simultaneously suggested pulling away and moving toward.

Preserve the operation:

> **SECOND LOOK CHANGES STANDING.**

Do not preserve the exact anatomy, webbing, hand placement, landscape, or palette.

The discovery is perceptual and relational, not stylistic.

---

# REQUIRED PRE-PROMPT QUESTION

Before every CF-06:

> **WHAT MUST THIS IMAGE DO VISUALLY THAT THE PREVIOUS IMAGE COULD NOT DO?**

If the answer is vague, decorative, or conceptual rather than morphological:

> **BLOCK THE PROMPT.**
