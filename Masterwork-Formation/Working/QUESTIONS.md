# Working Questions

## Instrument questions
- Which categories repeatedly produce useful evidence?
- Which categories produce biography without compositional value?
- When should a dossier split one work from an author's whole oeuvre?
- How should evidentiary survivability be scored or described?
- How should disputed attribution be represented?
- How do we distinguish formal decision from later critical reconstruction?

## Dante questions
- How much of the *Commedia*'s architecture can be dated relative to exile?
- What can be known about the sequence of composition across the three cantiche?
- How did early readers understand the work's genre?
- Which formal features are distinctly Dantean across his works and which belong specifically to the *Commedia*?
- What was genuinely novel about the reader's role in the poem relative to preceding traditions?
- How much of the architectural confidence comes from inherited cosmology versus Dante's formal innovation?
