# Dante — Sources

This file should accumulate the primary and secondary evidence used in the dossier.

## Primary / near-primary materials to consult
- *Commedia*
- *Convivio*
- *De vulgari eloquentia*
- Dante's political and personal letters, with attribution cautions where relevant
- early commentaries and manuscript tradition where useful

## Secondary research categories
- biography
- textual transmission
- manuscript history
- composition chronology
- Dante's philosophical sources
- Virgilian inheritance
- vernacular language history
- political exile
- early reception
- commentary tradition

## Evidence caution
No autograph manuscript of the *Commedia* survives.

Therefore:
- do not invent draft sequences
- do not infer rejected alternatives from final form alone
- distinguish securely documented composition history from later reconstruction

## Source hierarchy for this project
Prefer, where available:

1. surviving contemporary documentary evidence
2. primary writings
3. manuscripts / textual witnesses
4. early commentary
5. strong modern scholarship
6. later retrospective claims
7. project interpretation

This hierarchy is not absolute, but it should govern default confidence.
