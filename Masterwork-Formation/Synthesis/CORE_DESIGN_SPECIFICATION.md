# Core Design Specification

## Status

Working specification for the **Fixed Core / Deposit Body** of the Relational Return.

This document defines what the core must do **before** story, world, character, topic, or genre is chosen.

The core is not yet content.

It is a functional architecture.

---

# I. Governing Purpose

The core must support two valid encounters with the same material.

First encounter:

> **THIS MAKES SENSE.**

Second encounter, after independent contact:

> **THIS STILL MAKES SENSE — BUT NOT IN THE SAME WAY.**

Therefore the core must be able to survive:

FIRST SIGHT
+
CHANGED RELATION
+
SECOND SIGHT.

The core fails if the second sight merely proves the first sight foolish.

The core succeeds when the first sight remains locally warranted but becomes visibly partial.

---

# II. Core Law

> **THE CORE MUST CONTAIN ENOUGH OF THE PIECES FOR THE FIRST READING TO BE WARRANTED, WHILE LEAVING AT LEAST ONE CONSEQUENTIAL RELATION UNSETTLED.**

This is the central design constraint.

The missing element should preferably be:
- causation;
- provenance;
- obligation;
- sequence;
- identity;
- jurisdiction;
- dependency;
- boundary;
- scale;
- temporal relation;

rather than simply:
- a hidden fact;
- a secret clue;
- a missing name;
- a puzzle answer.

The work should not depend on withholding trivia.

It should depend on the difference between:
WHAT IS PRESENT
and
HOW WHAT IS PRESENT IS RELATED.

---

# III. The First Reading Must Be Whole Enough to Live

The first traversal must not feel like setup for a trick.

It should contain:
- a coherent field;
- meaningful recurrence;
- enough causal or emotional legibility to support investment;
- enough stability for memory;
- enough local truth that a receiver can reasonably trust it.

The first reading should produce a real account.

Not the final account.

A real one.

Working test:

> **WOULD THE FIRST HALF STILL BE WORTH EXPERIENCING IF THE HANDOFF NEVER CAME?**

If no, the core is merely bait.

---

# IV. The Core Must Contain Returnable Material

The core needs elements capable of carrying different standing on re-encounter.

Preferred returnable units:

- a sentence;
- a scene;
- an image;
- an object;
- a route;
- a gesture;
- a document;
- a repeated phrase;
- a decision;
- a relationship;
- a place;
- a temporal sequence.

At least several of these should remain materially unchanged between first and second encounter.

The receiver must be able to say:

> **I HAVE SEEN THIS BEFORE.**

And then:

> **I DID NOT SEE THIS BEFORE.**

That paradox is central.

---

# V. Recurrence Must Be Structural, Not Decorative

Repetition is required.

But recurrence must do work.

A repeated element should change because its relation changes.

Examples in abstract form:

OBJECT_A
first reads as
CARE.

After handoff:
OBJECT_A
may read as
CONTROL.

Or:

SENTENCE_A
first reads as
REASSURANCE.

After handoff:
SENTENCE_A
may read as
WITHHELD KNOWLEDGE.

Or:

ROUTE_A
first reads as
ESCAPE.

After handoff:
ROUTE_A
may read as
ABANDONMENT.

The material does not change.

Its standing does.

---

# VI. Ambiguity Must Be Bounded

The first reading cannot be so ambiguous that anything could mean anything.

That would destroy warrant.

The core needs:

ENOUGH CLARITY
TO SUPPORT TRUST

and

ENOUGH OPEN RELATION
TO SURVIVE CONTACT.

Therefore:

AMBIGUITY
MUST BE
RELATIONAL,
NOT
TOTAL.

The work may leave open:
- why;
- because of whom;
- under whose authority;
- in what sequence;
- with what obligation;
- from whose perspective.

But it should not leave everything indeterminate.

---

# VII. Receiver Investment Must Form Before the Seam

The receiver should care about the first relation before contact.

Investment may be:

## Cognitive
"I think I understand what happened."

## Emotional
"I trust / fear / care about this person."

## Ethical
"I think someone is responsible."

## Practical
"I know what should happen next."

## Spatial
"I know where I am."

## Temporal
"I know what came before what."

## Relational
"I know who stands in what relation to whom."

The seam becomes consequential only if some investment already exists.

---

# VIII. The Core Must Invite a Seam Without Announcing It

The work should not say:

"Later, you will discover that this is incomplete."

That destroys the first reading.

Instead, the core should contain one or more **jurisdictional edges**:
places where a reasonable receiver can continue without realizing that the work itself is not entitled to settle what lies beyond.

The seam may be latent in:
- an absent source;
- an institutional decision;
- an unverified account;
- an offstage event;
- a missing provenance chain;
- a future outcome;
- an external record;
- a boundary crossing.

The receiver need not know that the seam is a seam until the handoff occurs.

---

# IX. The Core Must Not Require the Seam to Be Good

This is essential for deposit.

If the live layer disappears, the core must still:
- possess form;
- support interpretation;
- reward attention;
- contain recurrence;
- hold tension;
- remain re-readable;
- be worth preserving.

Therefore:

> **THE CORE MUST BE A WORK BEFORE IT BECOMES PART OF A TWO-BODY WORK.**

The encounter body deepens it.

It does not rescue it.

---

# X. The Core Must Preserve First-Pass Memory

Second sight requires memory.

The core should therefore include memorable anchors:
- repeated objects;
- compressed phrases;
- strong visual motifs;
- recurring locations;
- distinct relational patterns;
- structural echoes.

The receiver should not need perfect recall.

The work itself should carry enough recurrence to reactivate the first sight.

---

# XI. The Core Must Tolerate More Than One Delta

A handoff may produce a change the author did not predict.

Therefore the core should not be designed around one single inevitable reinterpretation.

Bad design:

EVERYTHING POINTS
TO THE TWIST.

Better design:

THE HANDOFF
CHANGES ONE OR MORE
RELATIONS,
AND DIFFERENT RECEIVERS
MAY NOTICE DIFFERENT CONSEQUENCES.

The core must support:
- plural but bounded rereading;
- receiver-specific delta;
- unresolved remainder.

---

# XII. The Core Must Preserve Local Standing

Characters, voices, records, or objects should not exist merely as tokens in the author's later reveal.

Whatever appears in the first reading must retain some local integrity.

This prevents:

FIRST PASS
FROM BECOMING
A LIE TOLD BY THE AUTHOR
FOR THE SAKE OF
THE SECOND PASS.

The core must not sacrifice first-pass dignity for later cleverness.

---

# XIII. Scale

The core should be long enough for:
- trust;
- pattern;
- memory;
- recurrence;
- attachment.

But short enough that return remains viable.

A receiver must be willing and able to re-enter substantial earlier material.

Therefore the initial design should favor:

**DENSE RETURNABILITY OVER MAXIMUM LENGTH.**

The exact scale is not yet fixed.

But the design bias should be toward:
- bounded work;
- strong recurrence;
- revisitable units;
- identifiable internal landmarks.

A sprawling work can still qualify, but only if its return path is formally supported.

---

# XIV. Minimum Core Components

Before subject matter is chosen, the core appears to require at least:

## 1. A stable field
A world, situation, relation, or arrangement that can be understood.

## 2. A guide structure
Not necessarily a narrator.
Something helps the receiver orient.

## 3. Three or more returnable anchors
Elements that survive both readings.

## 4. One consequential but unsettled relation
The seam depends on this.

## 5. A receiver investment point
A place where the receiver forms a judgment, trust, expectation, or obligation.

## 6. A latent jurisdictional edge
A point the core itself is not entitled to settle.

## 7. A return path
The work must make second encounter structurally natural.

## 8. A remainder
Something not resolved even after contact.

---

# XV. Core Failure Modes

## 1. Puzzle Core
The first pass exists only to hide the answer.

## 2. Empty Ambiguity
Nothing is clear enough to be revised.

## 3. Overdetermined Core
Only one rereading is possible.

## 4. Explanatory Core
The work teaches the framework instead of embodying it.

## 5. Disposable First Pass
The first reading becomes worthless after contact.

## 6. Interface Dependence
The core has no life without the live seam.

## 7. No Returnability
The receiver cannot practically or perceptually revisit the same material.

## 8. Synthetic Other Leakage
The core pre-authors what the external handoff is supposed to say.

---

# XVI. Core Design Test

Before subject matter is selected, any proposed core architecture should answer:

1. What can the receiver genuinely believe on first encounter?
2. Why is that belief warranted?
3. What relation remains consequentially unsettled?
4. What three elements can be re-encountered unchanged?
5. What will make those elements stand differently later?
6. Where does receiver investment form?
7. Where is the jurisdictional edge?
8. Can the first reading survive if the handoff never occurs?
9. Can the second reading deepen rather than cancel the first?
10. Can more than one delta remain possible?
11. What remains unresolved after second sight?
12. Would the core still be worth preserving if every current interface disappeared?

If these cannot be answered, subject matter is premature.

---

# XVII. Minimum Compression

The fixed core must:

> **FORM A WARRANTED FIRST WORLD, HOLD ONE CONSEQUENTIAL RELATION OPEN, PRESERVE RETURNABLE MATERIAL, AND SURVIVE BEING SEEN TWICE.**

Or:

**COHERE
-> INVEST
-> LEAVE RELATION OPEN
-> PRESERVE
-> RETURN
-> DEEPEN.**
