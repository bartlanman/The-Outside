# Patterns Not Yet Earned

This file holds patterns that appear promising but have not yet been independently supported across enough dossiers to become project doctrine.

## Candidate pattern 001
LOSS OF POSITION
-> POSITION BECOMES VISIBLE
-> MULTIPLE POSITIONS BECOME THINKABLE
-> ARCHITECTURE OF PASSAGE

Origin: Dante pilot dossier.

Status: UNWARRANTED CROSS-AUTHOR PATTERN.

## Candidate pattern 002
THE STRONGER THE ARCHITECTURE, THE MORE IMPORTANT THE TEST AGAINST TOTALIZATION.

Origin: Dante + existing Outside architecture.

Status: PROJECT HYPOTHESIS, NOT HISTORICAL LAW.

## Candidate pattern 003
GREAT AUTHORSHIP MAY INVOLVE A CHANGE OF OFFICE BETWEEN EXPERIENCE AND COMPOSITION.

Origin: Dante traveler / later poet distinction.

Status: UNTESTED.

UNTESTED ACROSS DOSSIERS.
