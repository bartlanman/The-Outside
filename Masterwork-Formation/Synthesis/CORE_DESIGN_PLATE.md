# Core Design Specification — Plate

## BEFORE STORY

THE CORE MUST ALREADY KNOW
WHAT IT HAS TO DO.

↓

# FIRST LAW

THE FIRST READING
MUST DESERVE
TO HAVE BEEN BELIEVED.

↓

# CORE REQUIREMENT

ENOUGH PIECES
TO FORM
A REAL ACCOUNT.

BUT

AT LEAST ONE
CONSEQUENTIAL RELATION
REMAINS UNSETTLED.

↓

# NOT:

HIDDEN FACT
SECRET CLUE
PUZZLE ANSWER.

# PREFER:

CAUSATION
PROVENANCE
OBLIGATION
SEQUENCE
IDENTITY
JURISDICTION
BOUNDARY.

↓

# FIRST SIGHT

THIS MAKES SENSE.

↓

# RETURNABLE ANCHORS

SAME SENTENCE
SAME OBJECT
SAME SCENE
SAME IMAGE
SAME ROUTE
SAME GESTURE.

↓

# HANDOFF

RELATION CHANGES.

↓

# SECOND SIGHT

THIS STILL MAKES SENSE.

BUT NOT
IN THE SAME WAY.

↓

# CORE LAW

> I HAVE SEEN THIS BEFORE.

THEN:

> I DID NOT SEE THIS BEFORE.

↓

# AMBIGUITY

BOUNDED.

ENOUGH CLARITY
FOR TRUST.

ENOUGH OPEN RELATION
FOR RETURN.

↓

# INVESTMENT

THE RECEIVER
MUST CARE
BEFORE THE SEAM.

↓

# STABILITY

THE CORE
DOES NOT CHANGE
TO CREATE
THE SECOND READING.

↓

# DEPOSIT TEST

IF THE LIVE SEAM
DIES,

THE CORE
MUST STILL
BE WORTH HAVING.

↓

# MINIMUM COMPONENTS

STABLE FIELD
+
GUIDE STRUCTURE
+
RETURNABLE ANCHORS
+
ONE OPEN RELATION
+
INVESTMENT POINT
+
JURISDICTIONAL EDGE
+
RETURN PATH
+
REMAINDER.

↓

# COMPRESSION

COHERE
-> INVEST
-> LEAVE RELATION OPEN
-> PRESERVE
-> RETURN
-> DEEPEN.

↓

# NEXT QUESTION

WHAT SUBJECT MATTER
CAN CARRY THIS

WITHOUT BECOMING
A PUZZLE,
A THESIS NOVEL,
OR
AN AI DEMO?
