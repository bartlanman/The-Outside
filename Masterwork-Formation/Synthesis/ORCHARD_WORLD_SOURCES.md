# 1. Virginia Cooperative Extension — Growing Apples in Virginia

URL:
https://www.pubs.ext.vt.edu/content/pubs_ext_vt_edu/en/422/422-023/422-023.html

Supports:
- apple varieties do not reproduce true from seed;
- named varieties are propagated by budding / grafting;
- rootstocks affect tree size, productivity, support needs, and disease susceptibility;
- most apples require compatible cross-pollination;
- triploid varieties such as Winesap / Stayman are ineffective pollenizers;
- harvest windows for common Virginia varieties;
- maturity differs from ripeness;
- storage properties vary by cultivar;
- year-round fruit grower calendar.

Particularly useful world facts:
- late Virginia varieties include York and Winesap around October;
- harvest maturity should be judged by multiple indicators rather than color alone;
- some cultivars continue to improve / remain useful in storage;
- orchard care extends through every month.

Evidence status:
**DOCUMENTED HORTICULTURAL PRACTICE.**

# 2. Virginia Cooperative Extension — Crop Load Management / Chemical Fruit Thinning

URL:
https://www.pubs.ext.vt.edu/content/pubs_ext_vt_edu/en/SPES/SPES-134/SPES-134.html

Supports:
- commercial thinning deliberately removes developing fruit;
- thinning improves current fruit size / color;
- thinning can protect formation of the following year's flower buds;
- thinning can reduce biennial bearing;
- preserving every fruit in a heavy crop can reduce future production.

Evidence status:
**DOCUMENTED COMMERCIAL ORCHARD PRACTICE.**

Project interpretation:
The orchard materially demonstrates that more present output can reduce future capacity.

# 3. Virginia Cooperative Extension — Fire Blight

URL:
https://www.pubs.ext.vt.edu/SPES/spes-778.html

Supports:
- fire blight can kill trees;
- rootstock susceptibility matters;
- tolerant / resistant rootstocks can reduce tree mortality;
- cultivar and rootstock can have different susceptibility;
- excessive nitrogen and aggressive winter pruning can increase vulnerable shoot growth;
- infected wood removal is part of management.

Evidence status:
**DOCUMENTED PLANT-PATHOLOGY GUIDANCE.**

Project interpretation:
Visible scion condition does not exhaust whole-tree vulnerability.

# 5. Virginia Cooperative Extension — Spring Frost / Rootstock Effects

URL:
https://www.pubs.ext.vt.edu/SPES/spes-713/spes-713.html

Supports:
- spring frost is a major economic risk in apple production;
- bud vulnerability changes with developmental stage;
- post-bloom tissue can be far more frost-sensitive than dormant buds;
- Virginia research has examined rootstock effects on frost injury;
- Winchester's USDA hardiness-zone classification shifted warmer between the cited map periods;
- earlier development can narrow the buffer before damaging frost.

Evidence status:
**DOCUMENTED RESEARCH / EXTENSION.**

Project interpretation:
Risk is relational: temperature alone does not define damage; developmental state matters.

# Source Discipline

When building the eventual work:

- do not treat extension guidance as timeless law;
- practices differ by orchard system, cultivar, rootstock, weather, market, and year;
- use actual orchard consultation before canonizing highly specific production details;
- preserve differences between home-orchard guidance and commercial practice;
- do not make a single disease / frost / thinning rule universal.

The world should be horticulturally plausible, not a disguised extension manual.
