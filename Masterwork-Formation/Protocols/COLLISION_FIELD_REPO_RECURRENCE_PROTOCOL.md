# 0. PURPOSE

A Collision Field can obey every source-intake rule, gather new web material, and still fall back into a familiar gravitational basin because the repository itself contains concepts with enormous accumulated mass.

That is not discovery.

It may be recurrence masquerading as discovery.

The purpose of this protocol is to give the Collision Field a memory of what it has already used **before new Gravity begins to form**.

> **THE FIELD MUST KNOW ITS OWN ATTRACTION HISTORY BEFORE IT TRUSTS A NEW ATTRACTION.**

This protocol does not ban recurrence.

It distinguishes:
- recurrence that merely repeats;
- recurrence that deepens;
- recurrence that changes standing;
- recurrence that reveals a new perspective on a foundational axis;
- genuine new territory.

Crucial distinction:

> **A FOUNDATIONAL AXIS IS NOT AN EXHAUSTED BASIN.**

Some relations are constitutive of the whole project and may remain permanently generative.

Most importantly:

> **OTHERNESS / BOUNDARY / BETWEEN / διά ⇄ σύν MUST NOT BE MARKED "SATURATED" AS SUCH.**

What may become saturated is a **particular formulation or perspective** on that axis.

# 2. WHAT COUNTS AS "USED"

For each prior field, recover where available:

- target / emergent target;
- Gravity;
- title;
- major relational axis;
- recurring internal vocabulary;
- masterwork / historical operations activated;
- contemporary source domains;
- outside masses;
- third things / transformations;
- formal mutation;
- Masterwork contribution;
- receiver office;
- visual event / dominant motif;
- unresolved remainder.

Then classify them at two levels:

1. **FOUNDATIONAL AXES** — durable generative relations that the project may legitimately return to indefinitely;
2. **USED FORMULATIONS / ATTRACTION BASINS** — particular ways those axes have already been read, framed, or made gravitational.

A basin is broader than a keyword.

A foundational axis is broader still.

Examples:

`RESPONSE / REFUSAL / OTHERNESS / SILENCE / ACCESS`

may belong to one basin even when titles differ.

`AI COMPANION / SYNTHETIC PERSON / MODEL / DIGITAL RESURRECTION / AGENTIC AI`

may belong to a broader basin of:

`SYNTHETIC MEDIATION / RESPONSIVE REPRESENTATION / MACHINE-ACTED RELATION`

Likewise:

`TRACE / MEMORY / PROVENANCE / VERSION / ARCHIVE`

may represent a repeatedly used memory-standing basin.

> **DO NOT DEFEAT THE AUDIT BY RENAMING THE SAME GRAVITY.**

A foundational axis is a relation whose recurrence is expected because it belongs to the deep grammar of the project.

Current examples include:

- **OTHERNESS**
- **BOUNDARY / SEAM / BETWEEN**

- **PASSAGE / GATHERING**
- **WORLD / MODEL**
- **INHERITANCE / RETURN**
- **GROUND / FORM**

These are not "topics already used."

They are generative coordinates.

The audit must therefore ask:

> **WHICH PERSPECTIVE ON THE AXIS HAS ALREADY BEEN USED?**

not:

> **HAVE WE USED THE AXIS BEFORE?**

For example, Otherness has already been approached through:
- refusal;
- silence;
- independent standing;

- synthetic response.

That does **not** exhaust Otherness.

It records only some of the perspectives already traveled.

A future Collision Field may encounter Otherness through a different boundary condition entirely.

Hard law:

> **DO NOT CONFUSE A RECURRING AXIS WITH A REPEATED GRAVITY.**

And:

> **THE BOUNDARY IS A PERSPECTIVE GENERATOR.**

Changing:
- side;
- scale;
- medium;
- body;
- time;
- permeability;
- direction of passage;
- degree of gathering;

# 2B. διά ⇄ σύν AS PERSPECTIVAL ENGINE

`διά ⇄ σύν` is not a topic to "use up."

It is a way of listening to relation.

**διά** can disclose:
- through;
- across;
- apart;
- passage;
- separation;
- dispersal;
- crossing;
- differentiation.

**σύν** can disclose:
- with;
- together;
- gathering;
- coordination;
- composition;
- holding;
- belonging.

Their relation is not one fixed binary.

At any boundary, the field may ask:

- what is passing?
- what is gathering?
- what becomes distinct through passage?
- what becomes possible through holding?
- what does gathering exclude?
- what does passage destroy?
- what crosses without belonging?
- what belongs without collapsing?
- where does the boundary move?
- who experiences the boundary from which side?
- what appears when the scale changes?
- what becomes Other only because a relation formed?

Therefore:

> **OTHERNESS IS NOT A SINGLE OBJECT ON ONE SIDE OF A BOUNDARY.**

It may arise through the changing relation of:
**διά ⇄ σύν**.

The recurrence audit must protect this generativity rather than suppress it.

# 3. USAGE STATES

Each basin should be assigned one provisional state.

## A. SATURATED FORMULATION

A particular interpretation, framing, or operation has been repeatedly used across multiple Collision Fields / syntheses with little remaining change of standing.

Default behavior:
**DO NOT LET THAT FORMULATION BECOME PRIMARY GRAVITY AGAIN WITHOUT A MAJOR DELTA.**

A foundational axis itself must never be labeled saturated merely because several of its perspectives have been explored.

## B. ACTIVE / HEAVILY USED

Still productive, but already carrying enough project mass that it can capture unrelated material.

Default behavior:
**DE-PRIORITIZE DURING EARLY GATHER. REQUIRE NEW TERRITORY FOR PROMOTION.**

## C. USED / OPEN

Previously encountered but not exhausted.

Default behavior:
**MAY REENTER IF NEW CONTACT CHANGES IT.**

## D. REMAINDER / UNRESOLVED

Previously touched but deliberately left open.

Default behavior:
**AVAILABLE FOR REACTIVATION. DO NOT ASSUME ITS PRIOR FORMULATION.**

## E. UNDERDRAWN / FOREIGN

Little or no meaningful prior Collision Field use.

Default behavior:
**HIGH-VALUE CANDIDATE FOR SIDEWAYS DRAW, BUT NOT AUTOMATICALLY BETTER.**

The purpose is not novelty scoring.

It is gravitational awareness.

# 4. THE RE-ENTRY TEST

A previously used **formulation / basin** may become Gravity again only if at least one of the following is true.

A foundational axis does not require permission to reappear; its **specific perspective** must instead pass this test:

1. **NEW JURISDICTION** — a different kind of real-world standing changes what the basin is allowed to claim;
2. **NEW SCALE** — the relation behaves differently at a scale not previously explored;
3. **NEW MEDIUM CONDITION** — a genuinely new technical / cultural medium changes the operation, not merely the subject;
4. **NEW HISTORICAL OPERATION** — a different masterwork lineage changes the formal relation;
5. **NEW RECEIVER OFFICE** — the receiver can now do something structurally unavailable in the earlier run;
6. **NEW CONSEQUENCE** — the same relation produces a materially different cost / obligation / body / institution / action;
7. **NEW INVERSE** — outside material reverses or fractures the prior Gravity;
8. **NEW CAPACITY** — return to the basin becomes spiral rather than orbit; the field can now perceive / do something it could not before;
9. **PRIOR GRAVITY IS OVERTURNED** — the new run changes the standing of the old run.

If none applies:

> **RE-ENTRY DENIED — ORBIT DETECTED.**

Return to Gather.

# 5. AI / MODEL BASIN PROTECTION

The repository contains unusually high accumulated mass around:

- generative AI;
- responsive systems;
- model / world distinction;
- response / Otherness;
- synthetic authority;
- synthetic persons;
- personalization;
- provenance / verification;
- machine memory;
- persistent / generated identity;
- AI as realization layer;
- participant sovereignty inside responsive systems.

These are legitimate project concerns.

They are also gravitationally dangerous because they can make almost any new material appear to confirm the same cultural story.

Therefore:

> **AI MAY NOT BECOME THE PRIMARY GRAVITY MERELY BECAUSE AI IS THE CURRENT MEDIUM CONDITION.**

And:

> **THE FACT THAT A CONTEMPORARY PHENOMENON INVOLVES AI DOES NOT MAKE AI THE PHENOMENON'S MOST INTERESTING CULTURAL MASS.**

Before promoting an AI-centered Gravity, ask:

1. What is happening here if the AI vocabulary is removed?
2. What older human / biological / economic / ritual / legal / aesthetic / material process is actually under pressure?
3. What part of the phenomenon is new **because of the current medium**, rather than merely faster / larger / easier?
4. Has this exact AI basin already been used in the repository?
5. What changed standing this time?

If the answer is only:
- more responsive;
- more personalized;
- more synthetic;
- more agentic;
- harder to distinguish;
- easier to generate;

that is usually **intensification**, not a new Gravity.

Intensification alone does not earn re-entry.

# 9. PRE-GRAVITY PERSPECTIVE DELTA

Immediately before CF-02, compare the emerging candidate Gravity against the repo usage map.

State:

### FOUNDATIONAL AXIS
If present, name the enduring axis being revisited.

### NEAREST PRIOR PERSPECTIVE / BASIN
What previous Gravity, interpretation, or operation is most similar?

### PERSPECTIVE DELTA
What is actually different about the position, scale, boundary condition, medium, body, permeability, direction, time, passage, gathering, jurisdiction, consequence, receiver office, or standing?

### CHANGED STANDING
What can be said / done / perceived now that could not be said / done / perceived in the prior basin?

### VERDICT

Exactly one:

> **NEW TERRITORY**

> **SPIRAL RETURN — SAME AXIS, NEW PERSPECTIVE**

> **ORBIT — SAME FORMULATION, RETURN TO GATHER**

If verdict is ORBIT:

**CF-02 MAY NOT LOCK.**

A return to Otherness, Boundary, Between, or διά ⇄ σύν is not orbit by itself.

Orbit means the field has returned to substantially the same **perspective / formulation** without changed standing.
