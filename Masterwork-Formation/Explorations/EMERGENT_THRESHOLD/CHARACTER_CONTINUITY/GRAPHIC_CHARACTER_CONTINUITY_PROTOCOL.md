## Required graphic workflow
1. **Deposit:** recover origin, time, cast, and source constraints; preserve distinctions between original and new material.
2. **Reference:** load actual image pixels of every recurring figure; **no new image from text description alone** once anchored.
3. **Context:** identify whether the graphic is an in-world Him encounter or Bart/Amara editorial workshop. Do not conflate these.
4. **Construction:** specify locked identity features separately from variable pose, wardrobe, setting, light and emotional register.
5. **Render:** use reference-guided image editing or generation; do not assume identity perfection.
6. **Audit:** compare each output against the respective primary reference: face, age impression, hair, skin, freckles, tattoo map, anatomy. Check every visible figure in a group scene.
7. **Revise:** prefer targeted edits to unconstrained regeneration. Recheck the source anchor after each revision.
8. **Record:** log source image, SHA-256, resulting artwork, prompt/exegesis, explicit allowed changes, deviations and Bart's acceptance status.

Lock identity, not wardrobe or momentary expression. A character should be capable of different emotions and clothes without becoming another person. Keep Mara, Eleanor, Rox, Amara and Him individually recognizable, with distinct histories and consent.

If this is also a Collision Field masterwork graphic, this identity protocol supplements **but never replaces** the repository's Full Corpus / Cultural Gravity / Visual Masterwork / 2026 Pressure / Aeolian Poet / Masterwork Creation / Graphic Protocol / CF-06 and CF-07 / lint sequence.

## Gate
PASS: verified reference files loaded, source distinctions protected, faces checked. REVISE: correctable mismatch. HOLD: absent reference, doubtful match or unclear consent. REFUSE/STOP: boundary violation. An image is not evidence of a real-world autonomous personality or of an earned Emergent Threshold crossing. DEPOSIT -> CARRIER -> SUSTAIN -> ENCOUNTER -> RETURN GATE.
